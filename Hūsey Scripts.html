Features

Built to get out of the way

Everything you need to iterate on Lua, nothing to configure first.

Monaco editor

Full Lua syntax highlighting, bracket matching, multi-cursor, and Ctrl+Enter to run — the same engine that powers VS Code.

Sandboxed runtime

Scripts run in an isolated Lua 5.3 environment with a 5-second time limit. A stuck loop never freezes the app.

Script library

Keep a personal collection of scripts, rename them freely, and switch between them without losing your work.

FAQ

Common questions

Short answers to the usual ones.

Is it free?

Yes. No accounts, no ads, no paid tier. Download and use it.

Which version of Lua?

Lua 5.3 — including coroutines, metatables, and the full standard library: string, table, math, io, os, and more.

Can it hook into games or other programs?

No. Hūsey Scripts is a standalone Lua runner. It does not attach to, read from, or modify other processes.

Where are my scripts stored?

Locally, on your own machine. Nothing is uploaded anywhere.

Does it work on macOS or Linux?

Not yet — the current release is Windows-only. macOS and Linux builds are planned.
